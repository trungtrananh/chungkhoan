# chungkhoan skill

Reusable skill cho phân tích và giao dịch chứng khoán Việt Nam.

## Entry point

Đọc: [SKILL.md](./SKILL.md)

## Dùng nhanh

- Quét sau phiên: `$chungkhoan quét sau phiên hôm nay`
- Phân tích mã: `$chungkhoan đánh giá <TICKER> trong 7 phiên tới`
- Trade intraday: `$chungkhoan lập trade plan hôm nay theo danh mục hiện tại`
- Calibration: `$chungkhoan cập nhật track record rồi scan mới`
